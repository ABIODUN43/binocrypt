## 2. Pre-Implementation Lock Reconciliations

Before executing the BR-005.1 study, all four preregistered lock requirements were verified and frozen:

1. **Reconciliation of $E_0$ 14D Max-Drawdown Discrepancy:**  
   The slight discrepancy between `study_br005.py` (MaxDD = 54.16%, Net Return = +14.18%, Sharpe = +0.53) and `BR-005-ROBUSTNESS-AUDIT.md` (MaxDD = 50.69%, Net Return = +17.35%, Sharpe = +0.57) was traced to minor default LightGBM hyperparameter differences in the audit scratch script (`max_depth=4, num_leaves=15` vs canonical `max_depth=3, num_leaves=7`). The baseline $E_0$ is permanently frozen to the **canonical BR-005 specification** (`study_br005.py` parameters), yielding **Max Drawdown = 54.16%** and **Net Sharpe = +0.53**.
2. **Signal-to-Execution Timing Freeze:**  
   Signals are formed strictly from data available through Close of date $t$. Trades execute at `Open[t+1]` (00:00:00 UTC). On Binance Spot 24/7 markets, empirical verification confirms that `Close[t]` and `Open[t+1]` are adjacent milliseconds, with a maximum relative difference of $0.0025\%$ and a mean difference of $0.00001\%$, guaranteeing zero lookahead while modeling realistic start-of-day execution.
3. **Gate 3 Exposure-Matched Benchmark Definition:**  
   To cleanly isolate selection alpha from beta timing, Gate 3 evaluates candidates against an **Exposure-Matched Equal-Weight Benchmark** ($EW_{matched}(t) = w_{macro}(t) \cdot EW_{spot}(t) - \text{friction}$). Unhedged Equal-Weight ($EW_{unhedged}$, $w=1.0$) is retained as a secondary benchmark.
4. **Canonicalization of HMM State Labels:**  
   The 2-state Gaussian HMM ($E_3$) deterministically designates the state with the higher training-fold mean return as Bull ($S=1$). All state sequences are generated strictly via the causal forward recursion pass ($P(S_t = 1 \mid y_{1:t})$) without smoothed posteriors.
